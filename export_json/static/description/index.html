JSON Export

Free Module

Description

JSON Export is a module that adds the JSON option as an export format inside Odoo’s native export tool.

Screenshot

Installation & Configuration

1. Installation

Install the module from the Odoo Store.

2. Configuration

No specific configuration required.

3. Usage

When using Odoo’s export feature, the “JSON” option will appear in “Export Format”.

Technical Specifications

Odoo Version 19.0
Dependencies base, web, jsonifier
