Detailed Functionality

Two Powerful Notification Types

1. Pop-Up (Toast) Style

  • Appears as a non-intrusive popup on the screen.
  • Users can dismiss the notification after reading.
  • Supports rich text messages.
  • Ideal for: Alerts, reminders, updates.

2. Breaking News (Marquee)

  • Scrolling text banner at the top.
  • Customizable Styling: Background & Font colors.
  • Movement Control: Speed & Direction.
  • Font Size: Adjustable size.

Management & Tracking

State Workflow

Manage the lifecycle of your notifications:

  • Draft: Prepare message.
  • In Progress: Active and visible.
  • Finish/Cancelled: Stopped.
Read Receipts

Track engagement:

  • See who marked as "Read".
  • Filter active notifications.
  • Ensure critical info is received.

Configuration

Enable User Permissions

  1. Go to Settings > Users & Companies > Users.
  2. Select the user account to modify.
  3. In the Other tab, locate Web Notifications.
  4. Set the role to Web Notification Manager.
  5. Save the record and Refresh the browser page to apply changes.

Access the App

Refresh the browser to see the new Web Notification menu.

Creating a Notification

Simple Interface

  1. Name: Internal reference.
  2. Type: Pop-Up or Breaking News.
  3. Users: Use Show All for everyone or select specific users.
  4. Message: Rich text content.
  5. Submit: Click to move to In Progress stage.

Breaking News Options

  • Colors: Custom branding.
  • Animation: Scrolling effects.
  • Expiry: Auto-removal.
